# Release intent — v15.0.0

## What this release is about

This release re-aligns the token taxonomy with how designers actually organize
color in Figma. Semantic color tokens are regrouped into named families —
surface, text, border, icon, action, control, feedback, selection, and graphik —
that match Figma variable names 1:1, and a new intents layer (Primary,
Secondary, Brand, link) gives consumers coordinated color sets instead of
loose per-attribute values. Semantic colors ship in OKLCH with sRGB fallbacks.

## What consumers will care about most

- Figma parity: token names now match Figma variable names exactly, so a
  designer's spec translates directly to code with no translation table.

- Intents: `cdr-border`, `cdr-icon`, `cdr-surface`, `cdr-text`, and
  `cdr-text-emphasis` intent modules let consumers apply a coordinated
  Primary/Secondary/Brand/link set rather than composing individual tokens.

- Universal semantic layer: `--cdr-surface-*`, `--cdr-border-*`,
  `--cdr-text-*`, and `--cdr-icon-*` custom properties covering all canonical
  semantic colors, emitted in OKLCH with sRGB fallback values.

- Deprecate-don't-delete: the v14 utility mixins and the `color-background`
  family still ship — now marked `@deprecated` — so nothing hard-breaks this
  major. Removal is targeted for the next major.

## Breaking / migration notes

- The `cdr-color-background` foundation is renamed to the `--cdr-surface-*`
  taxonomy (and retuned). Old vars are still emitted, marked deprecated.
- `utility-map.scss` (the aggregated Sass map) is removed. Individual
  `$cdr-*` variables are unaffected.
- iOS output is reduced to text tokens (`CedarText.swift`); colors and sizes
  return in a later release. Android output is removed entirely (ADR-0005).
- The combined `cdr-text-*` Sass mixins moved: still emitted under
  `scss/utilities/` but deprecated; canonical replacements land in `@rei/cedar`.
- `node >= 24` is required to build.
