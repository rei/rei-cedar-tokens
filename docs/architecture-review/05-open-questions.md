# Open Questions

These are unresolved questions that affect schema design, filter rules, or the
migration sequencing in `04-migration-plan.md`. Grouped by theme; owner column left
blank for assignment.

## Taxonomy / Schema

| #   | Question                                                                                                                                                                                                                                                     | Why it matters                                                                                                                                           | Owner |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- |
| 1   | Is `overlay` (e.g. modal scrims) a **role**, an **interaction family**, or a usage context expressed through existing roles (`surface` + expression)?                                                                                                        | Determines whether a new role needs to be added to the schema or whether `color-background-modal-overlay` maps to an existing role/identity combination. |       |
| 2   | What is the complete, final Identity list? The taxonomy doc lists `brand, accent, warning, success, sale, trigger, neutral, natural, info, membership, rating, error` — are there gaps (e.g. a distinct "disabled" identity, or is disabled purely a state)? | Directly defines the enum used in schema validation and filter generation.                                                                               |       |
| 3   | How does **Expression** apply to non-color foundations (spacing rhythm, radius prominence, motion emphasis)? Is it the same 7-step scale (`trace…intense`) or foundation-specific scales?                                                                    | Affects whether Expression can be a single shared enum across foundations or needs per-foundation definitions.                                           |       |
| 4   | Confirm `inverse` and `link` are fully retired as identities in all downstream systems (Figma, component library docs), not just the canonical schema.                                                                                                       | Prevents drift where design files still reference `inverse`/`link` as if they were identities.                                                           |       |
